## Design Context

### Surface type
Demo — standalone HTML/SVG animations (no build step), previewed in a browser or Databricks notebook

### Audience
Customer / field demo (shown by SAs in customer conversations)

### Theme
Both — light default (#F9F7F4), dark variant via prefers-color-scheme

### Use case
Explain Lakebase architecture under the hood and how data flows in and out of Lakebase.

### Brand (locked)
- Palette: Lava 600 #FF3621 (10% accent), Navy 900 #0B2026, Light #F9F7F4
- Typography: DM Sans 400/500/700 + DM Mono
- Components: Du Bois first
- Voice: Databricks editorial-plain (no superlatives, plain statements)

### Additional constraints
- Self-contained single HTML files; must work offline-ish in a notebook iframe preview
- Respect prefers-reduced-motion
